# Simple Redis Cache

WordPress-плагін, який прискорює сайт за допомогою Redis. Він уміє дві речі, і кожна вмикається окремо:

- **об'єктний кеш** — WordPress тримає в Redis те, що інакше щоразу брав би з бази даних;
- **кеш HTML-сторінок** — готові сторінки віддаються відвідувачам прямо з Redis, ще до завантаження WordPress.

За бажанням плагін точково очищає кеш оновлених записів, чистить кеш Cloudflare і вручну прогріває кеш. Налаштування — у **Налаштування → Redis Cache**.

Потрібні WordPress 6.5+, PHP 8.1+, розширення PhpRedis і окремий приватний сервер Redis. Multisite не підтримується. Оновлення приходять через стандартний механізм WordPress з гілки `master` цього репозиторію.
