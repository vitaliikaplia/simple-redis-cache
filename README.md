# Simple Redis Cache

WordPress-плагін, який прискорює сайт за допомогою Redis. Він уміє дві речі, і кожна вмикається окремо:

- **об'єктний кеш** — WordPress тримає в Redis те, що інакше щоразу брав би з бази даних;
- **кеш HTML-сторінок** — готові сторінки віддаються відвідувачам прямо з Redis, ще до завантаження WordPress.

За бажанням плагін точково очищає кеш оновлених записів або при будь-якій зміні опублікованого контенту чистить увесь кеш сайту — HTML-сторінки, за бажанням і об'єкти, а також усю зону Cloudflare, — і вручну прогріває кеш. Ключі старих поколінь кешу після очищення він фоново прибирає з Redis. Налаштування — у **Налаштування → Redis Cache**.

На WordPress 6.9+ плагін реєструє інструменти для ШІ-агентів через WordPress Abilities API — стан кешу, очищення шару кешу й очищення кешу одного запису. Їх бачать агенти, підключені через [Simple MCP](https://github.com/vitaliikaplia/simple-mcp) 2.7+ або офіційний WordPress MCP Adapter.

Потрібні WordPress 6.5+, PHP 8.1+, розширення PhpRedis і окремий приватний сервер Redis. Multisite не підтримується. Оновлення приходять через стандартний механізм WordPress з гілки `master` цього репозиторію.
